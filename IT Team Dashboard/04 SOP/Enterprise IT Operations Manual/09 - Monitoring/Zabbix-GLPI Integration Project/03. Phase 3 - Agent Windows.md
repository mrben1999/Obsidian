# Phase 3 — Cài Agent Windows

Liên quan: [[02. Phase 2 - Agent Linux]] · [[../../04 - Active Directory/Tiered Administration Project/02. Phase 2 - OU Design]]

## 1. Mục đích
Triển khai Zabbix Agent2 trên toàn bộ Windows Server (DC, SQL, File Server) và Workstation quan trọng — deploy hàng loạt qua GPO, tương tự cách đã làm với GLPI Agent.

## 2. Phạm vi áp dụng
Domain Controller, Server Tier 1, Workstation cần giám sát (không nhất thiết toàn bộ 420 máy — ưu tiên Server trước, Workstation quan trọng như máy Kế toán/Server phòng ban nếu có).

## 3. Điều kiện tiên quyết
- [ ] Phase 1-2 hoàn tất.
- [ ] Có quyền deploy phần mềm qua GPO (đã thiết lập ở dự án AD Tiered Administration).

## 4. Quy trình thực hiện

### Bước 1 — Cài thủ công 1 máy test
Tải MSI từ `https://www.zabbix.com/download_agents`, cài silent:
```powershell
msiexec /i zabbix_agent2-7.0.0-windows-amd64-openssl.msi /qn `
  SERVER=192.168.1.20 `
  SERVERACTIVE=192.168.1.20 `
  HOSTNAME="HQ-PRD-DC-01" `
  TLSCONNECT=psk `
  TLSACCEPT=psk `
  TLSPSKIDENTITY="PSK-HQ-PRD-DC-01" `
  TLSPSKFILE="C:\Program Files\Zabbix Agent 2\zabbix_agent2.psk"
```

### Bước 2 — Sinh PSK cho từng máy Windows (PowerShell)
```powershell
$bytes = New-Object byte[] 32
(New-Object Security.Cryptography.RNGCryptoServiceProvider).GetBytes($bytes)
[BitConverter]::ToString($bytes) -replace '-','' | Out-File "C:\Program Files\Zabbix Agent 2\zabbix_agent2.psk" -Encoding ascii -NoNewline
```

### Bước 3 — Deploy hàng loạt qua GPO Startup Script (theo đúng pattern đã dùng cho GLPI Agent)
```powershell
# Install-ZabbixAgent.ps1 - gán vào GPO Startup Script, link vào OU Servers/Workstations
$installed = Test-Path "C:\Program Files\Zabbix Agent 2\zabbix_agent2.exe"
if (-not $installed) {
    $hostname = $env:COMPUTERNAME
    Start-Process msiexec.exe -ArgumentList `
      "/i \\HQ-PRD-MON-01\ZabbixDeploy\zabbix_agent2.msi /qn SERVER=192.168.1.20 SERVERACTIVE=192.168.1.20 HOSTNAME=$hostname TLSCONNECT=psk TLSACCEPT=psk TLSPSKIDENTITY=PSK-$hostname" `
      -Wait
}
```
> ⚠️ Script trên dùng `$env:COMPUTERNAME` làm Hostname Zabbix — chỉ chạy đúng nếu toàn bộ máy đã đặt tên **đúng chuẩn** [[../../01 - Governance/04. Naming Convention]] (ví dụ `HQ-PRD-SQL-01`) trước khi deploy agent.

### Bước 4 — Firewall Windows
```powershell
New-NetFirewallRule -DisplayName "Zabbix Agent" -Direction Inbound -Protocol TCP -LocalPort 10050 -Action Allow
```
(Nên đưa vào chính script GPO ở Bước 3 luôn để tự động hóa toàn bộ.)

## 5. Kiểm tra sau triển khai
```powershell
Get-Service "Zabbix Agent 2"   # phải Running
gpresult /r   # xác nhận máy đã nhận GPO deploy
```
- [ ] Toàn bộ Server/Workstation mục tiêu xuất hiện xanh trong Zabbix `Data collection > Hosts`.

## 6. Rollback (nếu có)
```powershell
msiexec /x zabbix_agent2-7.0.0-windows-amd64-openssl.msi /qn
```

## 7. Kiểm tra bảo mật
- [ ] PSK riêng biệt cho từng máy (không dùng chung 1 PSK cho toàn bộ Windows — nếu 1 máy bị lộ PSK, không ảnh hưởng máy khác).

## 8. Troubleshooting
| Sự cố | Nguyên nhân | Cách xử lý |
|---|---|---|
| GPO không cài được Agent | Antivirus/EDR chặn (tương tự vấn đề từng gặp với GLPI Agent) | Thêm exception cho `zabbix_agent2.exe` |
| Host trùng tên gây lỗi trên Zabbix | 2 máy vô tình cùng Hostname do đặt tên sai chuẩn | Rà soát lại theo [[../../01 - Governance/04. Naming Convention]] trước khi deploy hàng loạt |
