# Phase 1 — Cài Zabbix Server 7.0 LTS

Liên quan: [[00. Roadmap]] · [[../../01 - Governance/04. Naming Convention]] · [[../../03 - Installation/04 MariaDB|GLPI Deployment Manual - MariaDB]]

## 1. Mục đích
Dựng Zabbix Server làm nền tảng giám sát trung tâm cho toàn bộ hạ tầng — server, switch/router, service quan trọng.

## 2. Phạm vi áp dụng
1 server riêng biệt cho Zabbix (không cài chung máy với GLPI/DC) — đặt tên `HQ-PRD-MON-01` theo [[../../01 - Governance/04. Naming Convention]].

## 3. Điều kiện tiên quyết
- [ ] Debian 12 đã cài (đồng bộ chuẩn OS với GLPI Server đã dựng trước đó).
- [ ] Tối thiểu 4 vCPU / 8GB RAM / 100GB disk cho quy mô ~52 server + 420 workstation + switch (tăng dần theo số host giám sát).
- [ ] Đã tạo hostname/IP tĩnh theo chuẩn: `HQ-PRD-MON-01`.

## 4. Quy trình thực hiện

### Bước 1 — Cài repository Zabbix 7.0 LTS
```bash
wget https://repo.zabbix.com/zabbix/7.0/release/debian/pool/main/z/zabbix-release/zabbix-release_latest_7.0+debian12_all.deb
dpkg -i zabbix-release_latest_7.0+debian12_all.deb
apt update
```

### Bước 2 — Cài Zabbix Server + Frontend + Agent2 (dùng MySQL/MariaDB — đồng bộ engine với GLPI đã có)
```bash
apt install -y zabbix-server-mysql zabbix-frontend-php zabbix-nginx-conf \
  zabbix-sql-scripts zabbix-agent2 zabbix-sql-scripts mariadb-server
```

### Bước 3 — Tạo Database
```bash
mysql -u root -p << 'SQL'
CREATE DATABASE zabbixdb CHARACTER SET utf8mb4 COLLATE utf8mb4_bin;
CREATE USER 'zabbix'@'localhost' IDENTIFIED BY 'MatKhauZabbix_2026!';
GRANT ALL PRIVILEGES ON zabbixdb.* TO 'zabbix'@'localhost';
SET GLOBAL log_bin_trust_function_creators = 1;
FLUSH PRIVILEGES;
SQL

zcat /usr/share/zabbix-sql-scripts/mysql/server.sql.gz | mysql --default-character-set=utf8mb4 -u zabbix -p zabbixdb
```

### Bước 4 — Cấu hình zabbix_server.conf
```bash
sed -i "s/^# DBPassword=.*/DBPassword=MatKhauZabbix_2026!/" /etc/zabbix/zabbix_server.conf
```

### Bước 5 — Cấu hình Nginx + PHP-FPM
```bash
sed -i "s/# listen\s*80;/listen 80;/" /etc/zabbix/nginx.conf
sed -i "s/# server_name\s*example.com;/server_name mon.company.local;/" /etc/zabbix/nginx.conf
```

### Bước 6 — Khởi động dịch vụ
```bash
systemctl restart zabbix-server zabbix-agent2 nginx php8.2-fpm
systemctl enable zabbix-server zabbix-agent2 nginx php8.2-fpm
```

### Bước 7 — Hoàn tất setup qua web
Truy cập `http://HQ-PRD-MON-01/` (hoặc `http://mon.company.local/`) → làm theo Setup Wizard, nhập thông tin DB đã tạo ở Bước 3. Đăng nhập lần đầu: `Admin` / `zabbix` → **đổi mật khẩu ngay**.

### Bước 8 — Firewall
```bash
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 10051/tcp   # Zabbix Server nhận dữ liệu từ Agent
ufw enable
```

## 5. Kiểm tra sau triển khai
```bash
systemctl status zabbix-server   # active (running)
zabbix_server -V
```
- [ ] Đăng nhập được vào Frontend, đổi mật khẩu Admin mặc định.
- [ ] `Monitoring > Hosts` thấy sẵn host "Zabbix server" ở trạng thái xanh (đang tự giám sát chính nó qua Agent2 local).

## 6. Rollback (nếu có)
```bash
systemctl stop zabbix-server nginx
mysql -u root -p -e "DROP DATABASE zabbixdb;"
```
Xóa và cài lại từ Bước 3 nếu setup DB lỗi giữa chừng.

## 7. Kiểm tra bảo mật
- [ ] Đổi mật khẩu `Admin` mặc định ngay lập tức.
- [ ] Không public port 80/443 Zabbix Frontend ra Internet — chỉ truy cập nội bộ/VPN.
- [ ] Đặt mật khẩu DB mạnh (không dùng mẫu trong tài liệu này khi triển khai thật).

## 8. Troubleshooting
| Sự cố | Nguyên nhân | Cách xử lý |
|---|---|---|
| Frontend báo "Zabbix server is not running" | Service zabbix-server chưa start hoặc sai DBPassword | `journalctl -u zabbix-server -f` xem log lỗi cụ thể |
| Import schema SQL lỗi | Thiếu `log_bin_trust_function_creators=1` | Chạy lại lệnh SET GLOBAL ở Bước 3 trước khi import |
