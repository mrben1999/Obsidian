# Phase 9 — Dashboard NOC (Network Operations Center)

Liên quan: [[08. Phase 8 - Inventory Sync]] · [[00. Roadmap]] · [[../../12 - Reports/Dashboard|GLPI Deployment Manual - Dashboard]]

## 1. Mục đích
Dựng màn hình giám sát trung tâm (NOC Wallboard) hiển thị tình trạng hạ tầng theo thời gian thực — dùng cho phòng IT theo dõi liên tục và trình chiếu khi cần báo cáo nhanh.

## 2. Phạm vi áp dụng
Toàn bộ Host đã giám sát từ Phase 2-4.

## 3. Điều kiện tiên quyết
- [ ] Phase 1-8 hoàn tất, dữ liệu ổn định tối thiểu 1 tuần để Dashboard có ý nghĩa tham khảo thực tế.
- [ ] Có màn hình TV/màn hình rời đặt tại phòng IT (tùy chọn, không bắt buộc).

## 4. Quy trình thực hiện

### Bước 1 — Tạo Dashboard chính
`Dashboards > All dashboards > Create dashboard` → "NOC - Tong quan ha tang".

### Bước 2 — Widget đề xuất
| Widget | Nội dung |
|---|---|
| Problems | Danh sách sự cố đang mở, sắp xếp theo Severity |
| Host availability | Tỷ lệ Host online/offline theo Host Group |
| Graph (classic/SVG) | Băng thông Core Switch, CPU trung bình toàn bộ Server Tier 1 |
| Map | Sơ đồ mạng trực quan (xem Bước 3) |
| Top hosts | Top 10 Host có CPU/Disk cao nhất |
| Clock | Đồng hồ hiển thị giờ hệ thống (hữu ích khi đối chiếu thời gian sự cố) |

### Bước 3 — Network Map (trực quan hóa sơ đồ mạng)
`Data collection > Maps > Create map` — kéo-thả Host vào sơ đồ, vẽ liên kết theo đúng Network Diagram thực tế (đối chiếu [[../../02 - Infrastructure/00. Module Overview]]), màu sắc tự đổi theo trạng thái (xanh = OK, đỏ = down).

### Bước 4 — Chế độ trình chiếu Kiosk (cho màn hình TV phòng IT)
`Dashboard > (mở dashboard NOC) > Kiosk mode` (icon fullscreen) — tự động xoay vòng nếu có nhiều Dashboard, ẩn toàn bộ menu, chỉ hiện nội dung giám sát.

### Bước 5 — Liên kết chéo với Dashboard GLPI (đã xây ở GLPI Deployment Manual)
Không gộp 2 Dashboard làm 1 — giữ tách biệt vì mục đích khác nhau:
- **Zabbix Dashboard**: tình trạng kỹ thuật real-time (đang chạy tốt hay không).
- **GLPI Dashboard** (`12. Reports/Dashboard`): số liệu vận hành/kinh doanh (ticket, SLA, tài sản).
Đặt 2 link truy cập nhanh cạnh nhau trên Confluence/Wiki nội bộ hoặc trang chủ trình duyệt phòng IT.

## 5. Kiểm tra sau triển khai
- [ ] Dashboard hiển thị đúng dữ liệu real-time, không có widget lỗi "No data".
- [ ] Kiosk mode chạy ổn định liên tục trên màn hình TV thử nghiệm tối thiểu 24h không bị treo/crash trình duyệt.

## 6. Rollback (nếu có)
Không áp dụng — chỉnh sửa/xóa widget không ảnh hưởng dữ liệu giám sát gốc.

## 7. Kiểm tra bảo mật
- [ ] Nếu Dashboard trình chiếu ở khu vực có người ngoài IT đi qua (ví dụ sảnh chờ), rà soát không hiển thị thông tin nhạy cảm (IP nội bộ chi tiết, tên switch/server thật) — cân nhắc Dashboard rút gọn riêng cho khu vực công khai.

## 8. Troubleshooting
| Sự cố | Nguyên nhân | Cách xử lý |
|---|---|---|
| Map hiển thị sai trạng thái Host | Map chưa liên kết đúng Trigger để đổi màu | Kiểm tra lại cấu hình "Element" trong Map, gán đúng Host/Trigger |
| Kiosk mode tự đăng xuất sau vài giờ | Session timeout mặc định quá ngắn | Tăng session timeout riêng cho tài khoản dùng hiển thị Kiosk (tài khoản Zabbix riêng, quyền chỉ đọc — Read-only) |
