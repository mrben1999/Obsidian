# Phase 6 — GLPI API

Liên quan: [[05. Phase 5 - Trigger and Notification]] · [[../../10 - Security/API|GLPI Deployment Manual - Security/API]]

## 1. Mục đích
Chuẩn bị kết nối API giữa Zabbix và GLPI — nền tảng bắt buộc cho Phase 7 (Auto Ticket) và Phase 8 (Inventory Sync).

## 2. Phạm vi áp dụng
GLPI Server (`HQ-PRD-GLPI-01`).

## 3. Điều kiện tiên quyết
- [ ] GLPI REST API đã bật (`Setup > General > API` — xem chi tiết gốc tại GLPI Deployment Manual, mục Security/API).
- [ ] Có tài khoản GLPI riêng cho tích hợp (không dùng tài khoản cá nhân) — ví dụ `svc_zabbix_glpi`.

## 4. Quy trình thực hiện

### Bước 1 — Bật API trong GLPI
`Setup > General > API` → bật "Enable Rest API".

### Bước 2 — Tạo App-Token riêng cho Zabbix (không dùng chung token khác)
`Setup > General > API > Add a new client`:
| Trường | Giá trị |
|---|---|
| Name | Zabbix Integration |
| IPv4 range | IP của Zabbix Server (`HQ-PRD-MON-01`) — giới hạn phạm vi gọi API chỉ từ đúng server này |
| Application token | tự sinh — copy lưu lại |

### Bước 3 — Tạo tài khoản dịch vụ GLPI riêng cho tích hợp
`Administration > Users > Add` → `svc_zabbix_glpi`, Profile hạn chế (chỉ quyền tạo/xem Ticket + đọc Asset, không phải Super-Admin) — tuân thủ Least Privilege đúng như nguyên tắc đã áp dụng xuyên suốt toàn bộ dự án.

### Bước 4 — Lấy User-Token
Đăng nhập bằng `svc_zabbix_glpi` → `Cấu hình cá nhân > API` → sinh Personal Token.

### Bước 5 — Test kết nối
```bash
curl -X GET "https://glpi.company.local/apirest.php/initSession" \
  -H "Authorization: user_token <USER_TOKEN>" \
  -H "App-Token: <APP_TOKEN>"
```
Kết quả trả về `session_token` là thành công.

## 5. Kiểm tra sau triển khai
- [ ] `initSession` trả về session_token hợp lệ.
- [ ] Test tạo thử 1 Ticket qua API (`POST /apirest.php/Ticket`) rồi xóa thử để xác nhận quyền ghi hoạt động đúng.

## 6. Rollback (nếu có)
Vô hiệu hóa App-Token trong GLPI nếu cần ngắt kết nối khẩn cấp, không cần xóa hẳn cấu hình.

## 7. Kiểm tra bảo mật
- [ ] Giới hạn App-Token theo đúng dải IP nguồn (Bước 2) — token bị lộ cũng không gọi được từ nơi khác.
- [ ] Profile của `svc_zabbix_glpi` chỉ có đúng quyền cần thiết (Least Privilege), rà soát định kỳ giống mọi Service Account khác trong hạ tầng.

## 8. Troubleshooting
| Sự cố | Nguyên nhân | Cách xử lý |
|---|---|---|
| API trả 401 Unauthorized | Sai User-Token/App-Token, hoặc IP gọi không khớp dải đã giới hạn | Kiểm tra lại IP nguồn thực tế của Zabbix Server |
| API trả 400 khi tạo Ticket | Thiếu trường bắt buộc trong payload JSON | Xem log chi tiết response, đối chiếu API doc GLPI |
