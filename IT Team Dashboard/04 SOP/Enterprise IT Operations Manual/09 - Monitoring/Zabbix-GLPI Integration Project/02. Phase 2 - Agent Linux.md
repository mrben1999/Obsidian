# Phase 2 — Cài Agent Linux

Liên quan: [[01. Phase 1 - Cai Zabbix Server]] · [[../../01 - Governance/04. Naming Convention]]

## 1. Mục đích
Cài Zabbix Agent2 trên toàn bộ Server Linux (Debian/Ubuntu) — bao gồm GLPI Server, MariaDB, và các server Linux khác trong hạ tầng.

## 2. Phạm vi áp dụng
Toàn bộ Server Linux, đặt Hostname trong Zabbix **khớp chính xác** với tên server theo [[../../01 - Governance/04. Naming Convention]] (ví dụ `HQ-PRD-GLPI-01`) — để tra cứu chéo dễ dàng với GLPI Asset ở Phase 8.

## 3. Điều kiện tiên quyết
- [ ] Zabbix Server đã hoạt động (Phase 1).
- [ ] Firewall cho phép port 10050 (Agent lắng nghe) và Agent kết nối ra port 10051 (Server).

## 4. Quy trình thực hiện

### Bước 1 — Cài Agent2
```bash
wget https://repo.zabbix.com/zabbix/7.0/release/debian/pool/main/z/zabbix-release/zabbix-release_latest_7.0+debian12_all.deb
dpkg -i zabbix-release_latest_7.0+debian12_all.deb
apt update
apt install -y zabbix-agent2 zabbix-agent2-plugin-mongodb zabbix-agent2-plugin-postgresql
```

### Bước 2 — Cấu hình Agent (`/etc/zabbix/zabbix_agent2.conf`)
```ini
Server=192.168.1.20
ServerActive=192.168.1.20
Hostname=HQ-PRD-GLPI-01
TLSConnect=psk
TLSAccept=psk
TLSPSKIdentity=PSK-HQ-PRD-GLPI-01
TLSPSKFile=/etc/zabbix/zabbix_agent2.psk
```

### Bước 3 — Sinh khóa PSK (mã hóa kết nối Agent-Server — bắt buộc, không truyền dữ liệu cleartext)
```bash
openssl rand -hex 32 > /etc/zabbix/zabbix_agent2.psk
chmod 600 /etc/zabbix/zabbix_agent2.psk
chown zabbix:zabbix /etc/zabbix/zabbix_agent2.psk
cat /etc/zabbix/zabbix_agent2.psk   # copy giá trị này, nhập vào Zabbix Frontend khi tạo Host tương ứng
```

### Bước 4 — Khởi động
```bash
systemctl restart zabbix-agent2
systemctl enable zabbix-agent2
```

### Bước 5 — Tạo Host trên Zabbix Frontend
`Data collection > Hosts > Create host`:
| Trường | Giá trị |
|---|---|
| Host name | `HQ-PRD-GLPI-01` (khớp chính xác `Hostname=` trong file conf) |
| Host groups | `Linux Servers`, `PRD` |
| Interfaces | Agent — IP server |
| Templates | `Linux by Zabbix agent` |
| Encryption | PSK — dán identity + giá trị PSK từ Bước 3 |

## 5. Kiểm tra sau triển khai
```bash
zabbix_agent2 -t agent.ping
```
- [ ] Host chuyển trạng thái xanh (Available) trong `Data collection > Hosts`.
- [ ] Latest data hiển thị CPU/RAM/Disk cập nhật liên tục.

## 6. Rollback (nếu có)
```bash
systemctl stop zabbix-agent2
apt remove -y zabbix-agent2
```

## 7. Kiểm tra bảo mật
- [ ] TLS PSK bắt buộc bật cho **mọi** Agent — không để `TLSConnect=unencrypted` trên production.
- [ ] File PSK quyền `600`, chỉ user `zabbix` đọc được.

## 8. Troubleshooting
| Sự cố | Nguyên nhân | Cách xử lý |
|---|---|---|
| Host đỏ "Not available" | Sai IP Server, hoặc firewall chặn port 10050/10051 | `telnet <server-ip> 10051` kiểm tra kết nối |
| "ZBX_TCP_READ() failed" trong log | PSK identity/giá trị không khớp giữa Agent và Zabbix Frontend | Đối chiếu lại đúng giá trị đã dán ở Bước 5 |
