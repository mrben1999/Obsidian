## 1. Mục đích
Ghi nhận đầy đủ quyền đã Delegate cho từng nhóm — làm bằng chứng audit và tài liệu bàn giao.

## Ma trận Delegation (mẫu)
| Nhóm được Delegate | OU áp dụng | Quyền cụ thể | Ngày Delegate | Người thực hiện | Ticket/Change liên quan |
|---|---|---|---|---|---|
| GG_IT_Helpdesk | OU=Users | Reset Password, Force Change at Logon | | | |
| GG_IT_Helpdesk | OU=Workstations | Join Computer to Domain | | | |
| GG_IT_Helpdesk | OU=Users | Modify userAccountControl (Disable User) | | | |
