# GPO Documentation

Liên quan: [[00. Module Overview]] · [[Tiered Administration Project/08. Phase 8 - GPO Security Baseline]]

## 1. Mục đích
Danh sách toàn bộ GPO đang áp dụng trong domain, tránh tình trạng "GPO mồ côi" không ai biết mục đích.

## Danh sách GPO (mẫu)
| Tên GPO | OU áp dụng | Mục đích | Ngày tạo | Người tạo | Trạng thái |
|---|---|---|---|---|---|
| Default Domain Policy | Domain root | Password Policy mặc định | | | Active |
| Default Domain Controllers Policy | OU=Domain Controllers | Audit Policy, User Rights cho DC | | | Active |
| Tier0-DC-DenyLogon | OU=Tier0-DC | Chặn Tier1/2 Admin login DC | | | Active |
| Tier1-Server-DenyLogon | OU=Tier1-AppServers | Chặn Tier0/2 Admin login Server | | | Active |
| Tier2-Workstation-DenyLogon | OU=Workstations | Chặn Tier0/1 Admin login Workstation | | | Active |
| Baseline-AllServers-SecuritySettings | OU=Tier1-AppServers | Security Baseline (SMBv1 off, NTLMv2 only...) | | | Active |
| Baseline-AllWorkstations-SecuritySettings | OU=Workstations | Security Baseline Workstation | | | Active |

## Checklist duy trì
- [ ] Backup toàn bộ GPO định kỳ: `Backup-GPO -All -Path "D:\GPOBackup\$(Get-Date -Format yyyyMMdd)"`
- [ ] Review GPO không còn Link tới OU nào (orphaned) mỗi quý: `Get-GPO -All | Where {(Get-GPOReport -Guid $_.Id -ReportType XML) -notmatch "<LinksTo>"}`
- [ ] Mọi GPO mới phải test ở pilot OU trước khi rollout (xem Phase 8)
