# Group Matrix

Liên quan: [[00. Module Overview]] · [[Tiered Administration Project/03. Phase 3 - Security Groups (AGDLP)]]

## 1. Mục đích
Ma trận tra cứu nhanh: mỗi Security Group dùng để làm gì, cấp quyền gì, ai là thành viên hợp lệ.

## Ma trận nhóm (mẫu — điền/mở rộng khi vận hành thật)
| Nhóm | Loại | Mục đích | Thành viên hợp lệ | Quyền được cấp |
|---|---|---|---|---|
| GG_IT_Helpdesk | Global | Nhóm chức năng Helpdesk | Kỹ sư Tier 2 support | Xem [[Tiered Administration Project/06. Phase 6 - Delegation]] |
| GG_IT_Server | Global | Nhóm chức năng Server Team | Kỹ sư Tier 1 | Local Admin trên Server qua Restricted Groups |
| GG_Tier0-Admins | Global | Admin Domain Controller | adm0.* | Domain Admin, logon DC only |
| GG_Tier1-Admins | Global | Admin Server | adm1.* | Local Admin Server, logon Tier1 only |
| GG_Tier2-Admins | Global | Admin Workstation | adm2.* | Local Admin Workstation, logon Tier2 only |
| DL_FileServer_HR_ReadWrite | Domain Local | Quyền NTFS thư mục HR | GG_HR | Read/Write `D:\Shares\HR` |
| DL_AD_Helpdesk_ResetPassword | Domain Local | Quyền reset password | GG_IT_Helpdesk | Reset Password trên OU Users |

## Checklist duy trì
- [ ] Mọi Group mới tạo phải được thêm vào bảng này ngay
- [ ] Review hàng quý, gỡ Group không còn dùng
- [ ] Tuân thủ naming convention `GG_*`/`DL_*` — xem [[../01 - Governance/04. Naming Convention]]
