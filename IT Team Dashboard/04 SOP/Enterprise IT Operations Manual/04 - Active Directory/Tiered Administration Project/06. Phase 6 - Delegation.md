# Phase 6 — Delegation (Ủy quyền)

Liên quan: [[05. Phase 5 - Tiered Administration]] · [[03. Phase 3 - Security Groups (AGDLP)]] · [[../../14 - Standard Operating Procedures/01. Reset Password]]

## 1. Mục đích
Cấp đúng quyền cần thiết cho từng nhóm vận hành (Helpdesk, Server Team) mà **không cần** cấp Domain Admin — hiện thực hóa nguyên tắc Least Privilege. Sau Phase này, không ai ngoài Tier 0 Admin thực sự cần quyền Domain Admin.

## 2. Phạm vi áp dụng
Nhóm Helpdesk (Tier 2 support), nhóm Server Team (Tier 1 support), các phòng ban cần tự quản lý 1 phần OU riêng (nếu có).

## 3. Điều kiện tiên quyết
- [ ] Đã hoàn tất Phase 2 (OU) và Phase 3 (Security Group AGDLP).
- [ ] Đã xác định rõ ma trận quyền: nhóm nào được làm gì, trên OU nào.

## 4. Quy trình thực hiện

### Bước 1 — Ma trận Delegation chuẩn

| Nhóm | Được phép | Không được phép | OU áp dụng |
|---|---|---|---|
| GG_IT_Helpdesk | Reset Password, Unlock Account, Join Computer to Domain, Disable User | Delete OU, Delete GPO, Schema, DNS | `OU=Users`, `OU=Workstations` |
| GG_IT_Server | Quản trị IIS, SQL, File Server (ở tầng OS server, không phải AD object) | Quản trị Active Directory (User/Group/OU) | N/A — quyền cấp ở tầng Server, không qua AD Delegation |

### Bước 2 — Delegate quyền Helpdesk qua Delegation of Control Wizard
```powershell
# Cách làm qua GUI (khuyến nghị vì Wizard tự set đúng ACE, giảm rủi ro so với dsacls thủ công):
# 1. Mở Active Directory Users and Computers
# 2. Chuột phải OU=Users > Delegate Control
# 3. Chọn nhóm GG_IT_Helpdesk
# 4. Chọn task có sẵn: "Reset user passwords and force password change at next logon", "Modify the membership of a group" (nếu cần)

# Cách làm qua PowerShell/dsacls (cho việc audit lại quyền đã cấp):
dsacls "OU=Users,DC=company,DC=local" /I:S /G "COMPANY\GG_IT_Helpdesk:CA;Reset Password;user"
dsacls "OU=Users,DC=company,DC=local" /I:S /G "COMPANY\GG_IT_Helpdesk:WP;lockoutTime;user"
```

### Bước 3 — Delegate quyền Join Computer to Domain
```powershell
dsacls "OU=Workstations,DC=company,DC=local" /I:S /G "COMPANY\GG_IT_Helpdesk:CC;computer"
```

### Bước 4 — Delegate quyền Disable User (offboarding nhanh)
```powershell
dsacls "OU=Users,DC=company,DC=local" /I:S /G "COMPANY\GG_IT_Helpdesk:WP;userAccountControl;user"
```

### Bước 5 — Xác nhận KHÔNG có quyền thừa (Schema, DNS, Delete OU)
```powershell
# Kiểm tra Helpdesk không nằm trong bất kỳ nhóm nhạy cảm nào
Get-ADGroupMember -Identity "Schema Admins"
Get-ADGroupMember -Identity "Domain Admins"
Get-ADGroupMember -Identity "Enterprise Admins"
# GG_IT_Helpdesk KHÔNG được xuất hiện trong bất kỳ kết quả nào ở trên
```

## 5. Kiểm tra sau triển khai
Test thực tế bằng tài khoản Helpdesk thật (không phải Domain Admin):
- [ ] Đăng nhập ADUC bằng `adm2.nva` (thành viên GG_IT_Helpdesk) → reset password 1 user test → thành công.
- [ ] Thử xóa 1 OU bằng tài khoản này → phải bị từ chối quyền.
- [ ] Thử vào DNS Manager → phải bị từ chối/không thấy quyền quản trị.

## 6. Rollback (nếu có)
```powershell
# Gỡ 1 quyền delegate cụ thể nếu cấp nhầm phạm vi
dsacls "OU=Users,DC=company,DC=local" /R "COMPANY\GG_IT_Helpdesk"
```
Sau đó cấp lại chính xác theo đúng Bước 2-4.

## 7. Kiểm tra bảo mật
- [ ] Không Delegate quyền ở cấp Domain root (`DC=company,DC=local`) cho bất kỳ nhóm nào ngoài Tier 0 Admin — luôn Delegate ở cấp OU cụ thể, phạm vi hẹp nhất có thể.
- [ ] Review lại toàn bộ ACL đã Delegate mỗi 6 tháng, đối chiếu với Delegation Matrix tại [[../../01 - Governance/03. Responsibility Matrix (RACI)]].

## 8. Troubleshooting
| Sự cố | Nguyên nhân | Cách xử lý |
|---|---|---|
| Helpdesk reset password được nhưng user vẫn không đăng nhập lại được | Thiếu quyền ghi thuộc tính `pwdLastSet` cùng với quyền Reset Password | Bổ sung quyền qua Delegation Wizard, chọn đúng task "Reset user passwords and force change at next logon" (task này gộp sẵn 2 quyền) |
| Delegation Wizard không hiện OU cần chọn | Đang thao tác nhầm ở cấp Domain thay vì đúng OU | Điều hướng đúng OU trong ADUC trước khi chuột phải > Delegate Control |
