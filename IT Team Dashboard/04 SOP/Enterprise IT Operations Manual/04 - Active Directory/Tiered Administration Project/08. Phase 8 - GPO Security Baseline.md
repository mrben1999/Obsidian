# Phase 8 — GPO Security Baseline

Liên quan: [[05. Phase 5 - Tiered Administration]] · [[../../08 - Security/00. Module Overview]]

## 1. Mục đích
Áp dụng cấu hình bảo mật tối thiểu (Microsoft Security Baseline) trên toàn bộ Server và Workstation — tắt các giao thức/tính năng cũ dễ bị khai thác (SMBv1, NTLMv1, Guest, Anonymous, AutoRun, LLMNR), bật các cơ chế bảo vệ hiện đại phù hợp với phần cứng/OS hiện có.

## 2. Phạm vi áp dụng
Toàn bộ Server (Tier 0/1) và Workstation (Tier 2) trong domain.

## 3. Điều kiện tiên quyết
- [ ] Đã hoàn tất Phase 2 (OU) và Phase 5 (Tier).
- [ ] Đã tải bộ **Microsoft Security Compliance Toolkit** tương ứng phiên bản OS (Windows Server 2012 R2 baseline, Windows 10/11 baseline cho Workstation).
- [ ] Đã chuẩn bị OU/nhóm thí điểm (pilot) để test GPO trước khi áp toàn domain.

## 4. Quy trình thực hiện

### Bước 1 — Danh sách cấu hình bắt buộc DISABLE

| Cấu hình | Vị trí GPO | Lý do |
|---|---|---|
| SMBv1 | `Computer Configuration > Administrative Templates > Network > Lanman Workstation/Server` (hoặc PowerShell) | SMBv1 là giao thức cũ, không mã hóa, là vector tấn công của WannaCry/NotPetya |
| NTLMv1 | `Security Settings > Local Policies > Security Options > Network security: LAN Manager authentication level` = "Send NTLMv2 response only. Refuse LM & NTLM" | NTLMv1 dễ bị crack hash |
| Guest account | `Security Options > Accounts: Guest account status` = Disabled | Tài khoản không cần thiết, rủi ro truy cập ẩn danh |
| Anonymous enumeration | `Security Options > Network access: Do not allow anonymous enumeration of SAM accounts and shares` = Enabled | Chặn dò quét thông tin tài khoản không cần xác thực |
| AutoRun/AutoPlay | `Administrative Templates > Windows Components > AutoPlay Policies` = Disabled | Chặn mã độc lây qua USB tự động chạy |
| LLMNR | `Administrative Templates > Network > DNS Client > Turn Off Multicast Name Resolution` = Enabled | Chặn tấn công LLMNR Poisoning (lấy cắp hash NTLM qua Responder) |

### Bước 2 — Danh sách cấu hình bắt buộc ENABLE
| Cấu hình | Ghi chú |
|---|---|
| Windows Firewall (Domain + Private profile) | Bật mặc định, chỉ mở port cần thiết theo whitelist |
| BitLocker | Bắt buộc cho Laptop (Tier 2 di động) — xem [[../../07 - Endpoint Management/00. Module Overview]] |
| Windows Defender | Bật Realtime Protection, Cloud-delivered Protection |
| PowerShell Logging (Module Logging + Script Block Logging) | Ghi log toàn bộ lệnh PowerShell chạy trên máy — quan trọng cho Phase 9 Auditing |
| Credential Guard | ⚠️ **Chỉ khả dụng trên Windows 10/11 + phần cứng hỗ trợ (UEFI, Secure Boot, TPM 2.0, Virtualization-based Security)** — **KHÔNG khả dụng native trên Windows Server 2012 R2**. Áp dụng cho Workstation (Tier 2) đủ điều kiện phần cứng, không áp cho DC 2012 R2. |

### Bước 3 — Tạo GPO theo nhóm, không gộp chung 1 GPO khổng lồ
```powershell
New-GPO -Name "Baseline-AllServers-SecuritySettings"
New-GPO -Name "Baseline-AllWorkstations-SecuritySettings"
New-GPO -Name "Baseline-DomainControllers-SecuritySettings"

# Link vào đúng OU tương ứng
New-GPLink -Name "Baseline-AllServers-SecuritySettings" -Target "OU=Tier1-AppServers,OU=Servers,DC=company,DC=local"
New-GPLink -Name "Baseline-AllWorkstations-SecuritySettings" -Target "OU=Workstations,DC=company,DC=local"
New-GPLink -Name "Baseline-DomainControllers-SecuritySettings" -Target "OU=Domain Controllers,DC=company,DC=local"
```

### Bước 4 — Tắt SMBv1 qua PowerShell (bổ sung, không chỉ qua GPO)
```powershell
Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol -NoRestart
```

### Bước 5 — Thí điểm trước khi rollout toàn domain
1. Link GPO vào 1 OU nhỏ/nhóm pilot (5-10 máy) trước.
2. Theo dõi tối thiểu 3-5 ngày làm việc, thu thập phản hồi lỗi ứng dụng (một số phần mềm cũ có thể phụ thuộc NTLMv1/SMBv1).
3. Chỉ mở rộng ra toàn domain sau khi pilot ổn định.

## 5. Kiểm tra sau triển khai
```powershell
gpresult /h report.html /f   # xuất báo cáo GPO đang áp dụng trên 1 máy để đối chiếu
Get-SmbServerConfiguration | Select EnableSMB1Protocol   # phải là False
```
- [ ] SMBv1 đã tắt trên toàn bộ Server/Workstation.
- [ ] NTLMv1 đã chặn (chỉ còn NTLMv2).
- [ ] BitLocker đã bật trên toàn bộ Laptop.
- [ ] PowerShell Logging đã bật, log xuất hiện trong Event Viewer.

## 6. Rollback (nếu có)
```powershell
Set-GPLink -Name "Baseline-AllServers-SecuritySettings" -Target "OU=Tier1-AppServers,DC=company,DC=local" -LinkEnabled No
```
Gỡ Link tạm nếu phát hiện ứng dụng nghiệp vụ bị gãy do baseline quá chặt (ví dụ ứng dụng cũ bắt buộc SMBv1) — ưu tiên nâng cấp/thay thế ứng dụng cũ thay vì hạ chuẩn bảo mật vĩnh viễn.

## 7. Kiểm tra bảo mật
- [ ] Baseline áp dụng đồng nhất theo Tier — không có ngoại lệ "tạm thời" tồn tại quá 30 ngày mà không có kế hoạch khắc phục triệt để.
- [ ] Domain Controller (Tier 0) áp baseline khắt khe nhất, review riêng theo checklist CIS Benchmark for Domain Controllers.

## 8. Troubleshooting
| Sự cố | Nguyên nhân | Cách xử lý |
|---|---|---|
| Ứng dụng cũ không kết nối được File Server sau khi tắt SMBv1 | Ứng dụng/thiết bị legacy chỉ hỗ trợ SMBv1 | Đánh giá nâng cấp ứng dụng; nếu bắt buộc giữ tạm, cô lập thiết bị đó vào VLAN riêng thay vì bật lại SMBv1 toàn domain |
| Máy tính không nhận GPO mới | GPO chưa refresh hoặc link sai OU | `gpupdate /force`, kiểm tra `gpresult /r` |
