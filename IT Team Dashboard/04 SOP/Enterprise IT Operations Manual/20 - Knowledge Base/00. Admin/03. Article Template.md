# Article Template — Mẫu chuẩn bài viết KB

Liên quan: [[01. KB Setup Guide]]

> Copy mẫu dưới đây khi biên soạn bài viết KB mới. Điền đủ 4 phần bắt buộc: Symptom, Root Cause, Resolution, Notes.

---

## Metadata (điền trước khi nhập vào GLPI)
| Trường | Giá trị |
|---|---|
| Category | (chọn theo cây tại [[02. Category Structure]]) |
| Visibility / Target | Public toàn công ty ☐ &nbsp;&nbsp;&nbsp; Technician only ☐ |
| Tags/Keywords | (từ khóa giúp search full-text tìm ra bài, ví dụ: password, AD, reset) |
| Ngôn ngữ | Tiếng Việt |

## Tiêu đề bài viết
`[Mã lỗi/Hệ thống] Tên lỗi hoặc Tên hướng dẫn cụ thể`

Ví dụ: `[GLPI Agent] Sửa lỗi "The agent is requesting a configuration that has already been sent..."`

## 1. Tóm tắt hiện tượng (Symptom)
- Mô tả ngắn gọn lỗi xảy ra như thế nào, trong hoàn cảnh nào (khi làm gì thì gặp lỗi).
- Đính kèm ảnh chụp màn hình nếu có (upload trực tiếp vào ô Description của GLPI qua kéo-thả).

## 2. Nguyên nhân (Root Cause)
- Giải thích ngắn gọn tại sao xảy ra lỗi này — không chỉ nêu hiện tượng mà nêu đúng cơ chế gốc rễ.

## 3. Các bước xử lý (Resolution)
1. Bước 1: ...
2. Bước 2: ...
3. Bước 3: ...

> Với bài dành cho Technician: nên có lệnh CLI/cấu hình cụ thể, copy-paste được ngay.
> Với bài dành cho End-User: nên có ảnh chụp từng bước, ngôn ngữ đơn giản không dùng thuật ngữ kỹ thuật.

## 4. Thông tin bổ sung (Notes)
- Lưu ý quan trọng (rủi ro, trường hợp ngoại lệ).
- Liên kết bài viết liên quan trong KB.
- Link tải file đính kèm (driver, script, tài liệu) nếu có.
