# [O365] Hướng dẫn sử dụng cơ bản Office 365

## 1. Tóm tắt hiện tượng (Symptom)
Cần biết cách kích hoạt bộ Office (Word/Excel/PowerPoint) trên máy mới, hoặc cách lưu trữ/chia sẻ file qua OneDrive thay vì lưu cục bộ.

## 2. Nguyên nhân (Root Cause)
Quảng Việt cấp license Office 365 theo tài khoản email công ty — cần đăng nhập đúng tài khoản để kích hoạt bản quyền, đồng thời khuyến khích lưu file trên OneDrive để tự động backup và truy cập từ nhiều thiết bị.

## 3. Các bước xử lý (Resolution)
**Kích hoạt Office trên máy mới:**
1. Mở bất kỳ ứng dụng Office (Word/Excel), chọn **Sign In**.
2. Đăng nhập bằng tài khoản email công ty.
3. Office tự kích hoạt bản quyền, không cần nhập product key riêng.

**Lưu file lên OneDrive:**
1. Mở File Explorer, tìm mục **OneDrive - Quang Viet** trong danh sách thư mục bên trái.
2. Lưu file công việc vào đây thay vì Desktop/Local Disk — file sẽ tự động đồng bộ lên cloud.
3. Chia sẻ file cho đồng nghiệp: chuột phải file > **Share** > nhập email người cần chia sẻ.

## 4. Thông tin bổ sung (Notes)
- Dung lượng OneDrive mặc định: 1TB/tài khoản — nếu cần thêm, liên hệ IT.
- File lưu trên Desktop/Local Disk **không được backup tự động** — khi máy hỏng có thể mất dữ liệu, luôn ưu tiên lưu vào OneDrive.
