> Sơ đồ luồng dữ liệu theo VLAN/Subnet/Zone (DMZ, LAN, Server Farm, Guest...).

```
![[Network - Logical Topology.png]]
```

### Sơ đồ nhanh (mermaid — cập nhật khi có thiết bị thật)
```mermaid
graph TD
    Internet((Internet)) --> ISP1[ISP chính]
    Internet --> ISP2[ISP dự phòng]
    ISP1 --> FW[Firewall/NGFW]
    ISP2 --> FW
    FW --> Core[Core Switch]
    Core --> SW1[Access Switch - Văn phòng]
    Core --> SW2[Access Switch - Xưởng]
    Core --> SRV[Server Farm]
    Core --> STO[Storage/SAN]
    FW --> DMZ[DMZ Zone]
    FW --> VPN[VPN Gateway]
```
