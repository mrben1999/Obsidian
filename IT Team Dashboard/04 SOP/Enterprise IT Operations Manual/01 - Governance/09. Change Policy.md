# Change Policy

Liên quan: [[../19 - Change Management/00. Module Overview]] · [[../04 - Active Directory/07. AD Change Log]]

## 1. Mục đích
Quy định mọi thay đổi cấu hình hệ thống quan trọng phải qua quy trình kiểm soát (Change Management), tránh thay đổi tùy tiện gây sự cố diện rộng.

## Phân loại thay đổi
| Loại | Ví dụ | Yêu cầu phê duyệt |
|---|---|---|
| Standard (đã chuẩn hóa, rủi ro thấp) | Reset password, tạo user mới theo SOP | Không cần phê duyệt riêng, theo SOP có sẵn |
| Normal | Thay đổi GPO, thêm Delegation mới | Phê duyệt IT Manager qua Change Request |
| Emergency | Xử lý sự cố khẩn cấp ngoài giờ | Thực hiện trước, phê duyệt/ghi log sau trong 24h |
