# Documentation Standard

Liên quan: [[../17 - Templates/01. Document Template]]

## 1. Mục đích
Chuẩn hóa cấu trúc mọi tài liệu trong Enterprise IT Operations Manual — đảm bảo tính nhất quán, dễ tra cứu.

## Cấu trúc bắt buộc (10 mục)
```
1. Mục đích
2. Phạm vi áp dụng
3. Điều kiện tiên quyết
4. Quy trình thực hiện
5. Kiểm tra sau triển khai
6. Rollback (nếu có)
7. Kiểm tra bảo mật
8. Troubleshooting
9. Nhật ký thay đổi
10. Tài liệu tham khảo
```
Xem template dùng ngay tại [[../17 - Templates/01. Document Template]].

## Quy định bổ sung
- Mọi lệnh PowerShell/CLI phải ở dạng code block, copy-paste chạy được ngay (không viết lệnh giả định thiếu tham số).
- Mọi tài liệu đều có `tags` trong frontmatter YAML để hỗ trợ tìm kiếm/Dataview.
- Liên kết chéo bắt buộc dùng Wikilink `[[...]]`, không dùng URL tuyệt đối tới file khác trong vault.
