# Responsibility Matrix (RACI)

Liên quan: [[02. IT Roles]] · [[../04 - Active Directory/06. Delegation Matrix]]

## 1. Mục đích
Ma trận RACI (Responsible/Accountable/Consulted/Informed) cho các hoạt động IT quan trọng — làm rõ ai làm, ai chịu trách nhiệm cuối, ai cần tham vấn, ai cần biết.

## Ma trận mẫu
| Hoạt động | Helpdesk | Infra Engineer | IT Manager | HR |
|---|---|---|---|---|
| Reset Password | R | - | A | I |
| Thêm thành viên Domain Admins | I | R | A | - |
| Tạo tài khoản nhân viên mới | I | R | A | R (khởi tạo yêu cầu) |
| Thay đổi GPO Security Baseline | I | R | A | - |
| Duyệt Change Request lớn | I | C | A | - |

> R = Responsible (thực hiện) · A = Accountable (chịu trách nhiệm cuối) · C = Consulted (tham vấn) · I = Informed (thông báo)
