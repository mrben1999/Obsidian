# MFA Standard

Liên quan: [[00. Module Overview]] · [[../04 - Active Directory/Tiered Administration Project/01. Phase 1 - Admin Account Standardization]]

## 1. Mục đích
Quy định phạm vi bắt buộc áp dụng Xác thực đa yếu tố (MFA) trong doanh nghiệp.

## 4. Phạm vi bắt buộc MFA
| Đối tượng | Bắt buộc MFA? |
|---|---|
| Tài khoản Admin Tier 0/1 (`adm0.*`, `adm1.*`) | ✅ Bắt buộc |
| Truy cập VPN từ xa | ✅ Bắt buộc |
| Tài khoản Email/Office 365 (toàn bộ nhân viên) | ✅ Khuyến nghị bắt buộc |
| Tài khoản User thường đăng nhập nội bộ (Workstation) | Tùy đánh giá rủi ro, không bắt buộc ở giai đoạn đầu |

## Phương án kỹ thuật
- Với hạ tầng Windows Server 2012 R2 thuần (không có Azure AD/Entra ID), triển khai MFA qua giải pháp RADIUS OTP của bên thứ 3 (Duo Security, FortiAuthenticator) tích hợp NPS (Network Policy Server) cho VPN.
- Với Office 365, dùng Microsoft Authenticator (MFA gốc của Microsoft 365, không phụ thuộc AD tại chỗ).
