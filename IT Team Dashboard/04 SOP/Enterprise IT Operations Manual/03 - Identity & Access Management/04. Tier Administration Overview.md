# Tier Administration Overview

Liên quan: [[00. Module Overview]] · [[../04 - Active Directory/Tiered Administration Project/05. Phase 5 - Tiered Administration]]

## 1. Mục đích
Tóm tắt mô hình Tiered Administration ở góc độ chính sách (không đi sâu kỹ thuật — phần triển khai kỹ thuật chi tiết nằm ở [[../04 - Active Directory/Tiered Administration Project/05. Phase 5 - Tiered Administration]]).

## 2. Phạm vi áp dụng
Toàn bộ tài khoản quản trị hệ thống.

## 4. Tóm tắt mô hình
| Tier | Phạm vi | Rủi ro nếu bị xâm nhập |
|---|---|---|
| Tier 0 | Domain Controller, PKI, CA | Toàn bộ domain bị chiếm quyền |
| Tier 1 | Server ứng dụng (GLPI, SQL, File Server) | Mất dữ liệu/dịch vụ nghiệp vụ |
| Tier 2 | Workstation người dùng | Rủi ro cục bộ, điểm khởi đầu tấn công phổ biến nhất |

**Nguyên tắc cốt lõi:** credential của Tier cao không bao giờ xuất hiện trên máy Tier thấp hơn — đây là cách duy nhất chặn đường leo thang đặc quyền (privilege escalation) qua credential theft.
