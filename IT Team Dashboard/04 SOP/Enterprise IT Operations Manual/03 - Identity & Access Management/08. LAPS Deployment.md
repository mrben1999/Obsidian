# LAPS Deployment — Local Administrator Password Solution

Liên quan: [[00. Module Overview]] · [[../04 - Active Directory/Tiered Administration Project/05. Phase 5 - Tiered Administration]]

## 1. Mục đích
Đảm bảo mật khẩu Local Administrator trên mỗi máy trạm/server là **duy nhất, ngẫu nhiên, tự đổi định kỳ** — ngăn kẻ tấn công di chuyển ngang (lateral movement) bằng cách dùng chung 1 mật khẩu Local Admin trên toàn bộ máy (lỗi cấu hình rất phổ biến).

## 2. Phạm vi áp dụng
Toàn bộ Server (Tier 1) và Workstation (Tier 2). Không áp dụng cho Domain Controller (không có tài khoản Local Admin theo nghĩa thông thường).

## 3. Điều kiện tiên quyết
- [ ] Đã mở rộng AD Schema để hỗ trợ thuộc tính LAPS (`ms-Mcs-AdmPwd`).
- [ ] Domain Functional Level tương thích (2012 R2 hỗ trợ tốt).

## 4. Quy trình thực hiện
```powershell
# Trên máy Schema Master, mở rộng Schema cho LAPS
Import-Module AdmPwd.PS
Update-AdmPwdADSchema

# Cấp quyền đọc/ghi mật khẩu LAPS cho đúng nhóm (ví dụ Helpdesk chỉ đọc, không đổi)
Set-AdmPwdReadPasswordPermission -OrgUnit "OU=Workstations,DC=company,DC=local" -AllowedPrincipals "GG_IT_Helpdesk"
Set-AdmPwdResetPasswordPermission -OrgUnit "OU=Workstations,DC=company,DC=local" -AllowedPrincipals "GG_IT_Helpdesk"

# Cài đặt LAPS Client (GPO CSE) trên toàn bộ máy qua GPO, cấu hình:
# Computer Configuration > Administrative Templates > LAPS
# - Password Settings: 14 ký tự, đổi mỗi 30 ngày
# - Enable local admin password management: Enabled
```

## 5. Kiểm tra sau triển khai
```powershell
Get-AdmPwdPassword -ComputerName "HQ-IT-PC-001"   # phải trả về mật khẩu hiện tại
```
- [ ] Mỗi máy có mật khẩu Local Admin khác nhau.
- [ ] Chỉ nhóm được cấp quyền (Helpdesk/Admin) mới đọc được mật khẩu.

## 7. Kiểm tra bảo mật
- [ ] Quyền đọc mật khẩu LAPS phải giới hạn chặt — đây bản thân cũng là 1 loại "đặc quyền" cần audit.
