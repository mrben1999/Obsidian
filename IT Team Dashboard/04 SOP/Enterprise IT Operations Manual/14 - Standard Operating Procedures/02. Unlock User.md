# SOP: Unlock User

Liên quan: [[00. Module Overview]] · [[01. Reset Password]]

## 1. Mục đích
Quy trình mở khóa tài khoản bị lockout do nhập sai mật khẩu quá số lần cho phép.

## 4. Quy trình thực hiện
```powershell
Get-ADUser -Identity "nva" -Properties LockedOut   # xác nhận đang bị khóa
Unlock-ADAccount -Identity "nva"
```

## 5. Kiểm tra sau triển khai
```powershell
Get-ADUser -Identity "nva" -Properties LockedOut   # phải trả False
```

## 8. Troubleshooting
| Sự cố | Nguyên nhân | Cách xử lý |
|---|---|---|
| Unlock xong nhưng vài phút sau lại bị khóa | Có thiết bị/ứng dụng đang cache mật khẩu cũ tự động thử lại (điện thoại, ổ mạng) | Yêu cầu người dùng cập nhật mật khẩu trên toàn bộ thiết bị đang lưu (điện thoại, VPN client) |
| Lockout liên tục nhiều tài khoản cùng lúc | Có thể là tấn công brute-force | Báo ngay Security/IT Manager, xem [[../15 - Incident Response/00. Module Overview]] |
