# Attachments

Liên quan: [[04 SOP/Enterprise IT Operations Manual/00 - Home/00. Home]]

## Mục đích
Thư mục lưu trữ file đính kèm không phải Markdown: PDF, ISO, Scripts (PowerShell/Batch/EXE/MSI), Visio/Draw.io diagrams, Images, Backup configs.

## Cấu trúc đề xuất
```
Attachments/
├── Scripts/
│   ├── PowerShell/        (toàn bộ script .ps1 dùng trong các Phase/SOP, tách riêng khỏi Markdown để dễ chạy trực tiếp)
│   ├── Batch/
├── Diagrams/
│   ├── Network-Topology.vsdx
│   ├── Rack-Diagram.drawio
├── Configs/
│   ├── GPO-Backups/
│   ├── Firewall-Configs/
└── Documents/
    ├── Vendor-Contracts/
    └── Compliance-Evidence/
```

## Ghi chú thực tế
Khuyến nghị: mọi script PowerShell dài trong các Phase (04 - Active Directory/Tiered Administration Project) nên được tách thành file `.ps1` riêng lưu tại `Attachments/Scripts/PowerShell/`, chỉ giữ đoạn ngắn minh họa trong Markdown — giúp version control script dễ hơn (đặc biệt nếu dùng Git để quản lý vault này).

> 🟡 Cấu trúc đề xuất — chưa có file đính kèm thật, tạo dần khi vận hành.
