# Module 05 — Windows Server

Liên quan: [[04 SOP/Enterprise IT Operations Manual/00 - Home/00. Home]] · [[../04 - Active Directory/00. Module Overview]]

## Mục đích module
Tài liệu vận hành từng Server Role: File Server, Print Server, DNS, DHCP, IIS, Hyper-V, NPS, CA, WSUS, RDS. Mỗi Server Role dự kiến là 1 thư mục con riêng.

## Danh sách dự kiến
- File Server (quyền NTFS, Shadow Copy, DFS nếu có)
- Print Server
- DNS (Zone, Forwarder — liên kết [[../04 - Active Directory/00. Module Overview]])
- DHCP (Scope, Reservation)
- IIS (áp dụng cho GLPI — liên kết [[../13 - ITSM (GLPI)/00. Module Overview]])
- Hyper-V (liên kết [[../11 - Virtualization/00. Module Overview]])
- NPS (Network Policy Server — dùng cho RADIUS/MFA VPN, liên kết [[../03 - Identity & Access Management/06. MFA Standard]])
- CA (Certificate Authority nội bộ — liên quan LAPS/LDAPS)
- WSUS (Patch Management)
- RDS (Remote Desktop Services, nếu có)

> 🟡 Module này chưa được xây dựng sâu. Yêu cầu cụ thể "xây module 05 - Windows Server" (hoặc chỉ định 1 Server Role cụ thể, ví dụ "xây DNS/DHCP") để Claude triển khai đầy đủ.
