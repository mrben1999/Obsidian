# Module 08 — Security

Liên quan: [[04 SOP/Enterprise IT Operations Manual/00 - Home/00. Home]] · [[../04 - Active Directory/Tiered Administration Project/00. Roadmap]]

## Mục đích module
Chương bảo mật lớn nhất theo thiết kế gốc (~150 tài liệu dự kiến): Microsoft Baseline, Hardening, Tier Model, Least Privilege, Credential Protection, BitLocker, Defender, AppLocker, Firewall, TLS, SMB, NTLM, LDAP, PowerShell Logging, Audit, SIEM.

## Đã xây dựng riêng trong module này
- [[01. AppLocker - Block Browser and Office on Admin Accounts]] — chặn Chrome/Edge/Firefox/Outlook/Teams trên tài khoản Admin bằng Publisher Rule, kèm phương án dự phòng cho Windows 10/11 Pro không hỗ trợ AppLocker
