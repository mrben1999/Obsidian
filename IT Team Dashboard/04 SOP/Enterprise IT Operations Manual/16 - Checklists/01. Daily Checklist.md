# Daily Checklist

Liên quan: [[00. Module Overview]]

## DC Health
- [ ] Domain Controller online, không có Event ID lỗi nghiêm trọng (`eventvwr.msc` → System/Application, lọc Error)
- [ ] Replication AD không lỗi: `repadmin /replsummary`

## Backup
- [ ] Job backup đêm qua chạy thành công (kiểm tra log Backup Server)

## Event Log
- [ ] Rà soát nhanh Event ID 4740 (account lockout) — nhiều lockout bất thường có thể là dấu hiệu tấn công brute-force

## Antivirus
- [ ] Không có cảnh báo mã độc mới từ Windows Defender/AV trung tâm

## Disk
- [ ] Dung lượng ổ đĩa Server quan trọng (DC, GLPI, File Server) còn > 20%

## GLPI
- [ ] Không có ticket "Rất cao" (Critical) tồn đọng quá SLA

## DNS/DHCP
- [ ] Dịch vụ DNS/DHCP hoạt động bình thường, không có scope DHCP gần cạn IP
