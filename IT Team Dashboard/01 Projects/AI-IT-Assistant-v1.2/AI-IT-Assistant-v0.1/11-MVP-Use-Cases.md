# 11 — MVP Use Cases

## UC01 — Log analysis

Input: log/text/file.

Output:

- symptoms;
- likely root cause;
- evidence;
- next checks;
- safe commands;
- recommended fix.

## UC02 — Script generation

Input: requirement.

Output:

- script;
- explanation;
- test method;
- rollback/undo;
- warnings.

## UC03 — Code debugging

Input: repository/error.

Output:

- reproduction hypothesis;
- root cause;
- patch;
- tests;
- risk.

## UC04 — Runbook creation

Input: solved incident.

Output:

```text
Symptoms
Cause
Detection
Resolution
Verification
Rollback
Prevention
```

## UC05 — Incident report

Input: timeline/logs/actions.

Output:

- summary;
- timeline;
- impact;
- root cause;
- resolution;
- lesson learned.

## UC06 — IT research

Input: technical question.

Output:

- answer;
- assumptions;
- references;
- commands/examples;
- risks.

## UC07 — Daily report

Input: tasks/notes.

Output:

- completed;
- pending;
- blocked;
- risks;
- next actions.
