# 01 — Goals & Scope

## Goal

Tạo một AI IT Assistant dùng được trong công việc hằng ngày.

## Primary use cases

### Coding
- đọc repository;
- giải thích code;
- debug;
- refactor;
- viết test;
- review;
- tạo script.

### System
- phân tích command output;
- phân tích service;
- Linux/Windows;
- Docker;
- process/resource troubleshooting.

### Network
- phân tích cấu hình;
- DNS;
- HTTP;
- TCP/IP;
- connectivity troubleshooting.

### Data
- SQL troubleshooting;
- query explanation;
- log analysis;
- report generation.

### Documentation
- viết SOP;
- runbook;
- incident report;
- architecture note;
- checklist.

### Daily IT
- tổng hợp task;
- chuẩn hóa yêu cầu;
- tạo kế hoạch;
- phân tích ticket;
- tạo báo cáo.

## Non-goals

- autonomous production operations;
- 24/7 monitoring;
- self-hosted infrastructure;
- enterprise IAM;
- multi-user platform;
- full automation pipeline.

Những phần này chỉ xuất hiện ở các phase sau nếu MVP chứng minh được giá trị.
