## WORK PACKAGE 01 (WP-01): ENTERPRISE BACKUP VERIFICATION & ISOLATED RESTORE

### 1. Problem Analysis & Objective (WHY)

- **WHY:** Khôi phục hệ thống mà không qua khâu **Integrity Verification** là một thảm họa tiềm ẩn. Bản sao lưu có thể bị lỗi bit (Bit Rot), hỏng cơ sở dữ liệu `NTDS.dit` hoặc không thể đáp ứng thời gian khôi phục mục tiêu (**RTO - Recovery Time Objective**).
    
- **HOW:** Áp dụng chuỗi quy trình chuẩn Enterprise: **Backup Integrity Check -> Isolated Restore -> Multi-Service Validation (AD, DNS, SYSVOL, NETLOGON, LDAP, Kerberos, Event Logs) -> Measuring RTO**.
    

### 2. Comprehensive Workflow Diagram

Code snippet

```
flowchart TD
    A[Veeam / Backup Repository] --> B{1. Integrity Check: Health Check & CRC Verify}
    B -- FAIL --> C[STOP / NO-GO: Fix Backup Repository]
    B -- PASS --> D[2. Isolated Restore to VLAN_999]
    D --> E{3. Measure RTO Timer}
    E -- > 90 Mins --> F[WARNING: Review Storage / Network Bandwidth]
    E -- <= 90 Mins --> G[4. Multi-Service Validation]
    G --> H[Check Services: NETLOGON, SYSVOL, DNS, LDAP, Kerberos]
    G --> I[Check Event Logs: Directory Service, DNS, DFSR]
    H & I --> J{All Tests PASS?}
    J -- YES --> K[WP-01 PASSED - READY FOR PHASE 2]
    J -- NO --> L[ROLLBACK / CLEANUP LAB & RE-BACKUP]
```

### 3. Verification Commands & Diagnostics Suite (Isolated Lab)

Sau khi Restore VM DC01 vào `VLAN_999_Isolated_Lab` (Tên miền `qve.com`), chạy bộ lệnh kiểm tra toàn diện 7 thành phần:

PowerShell

```

# SCRIPT: WP01_Lab_Validation_Suite.ps1

Write-Host "`n=== 2. KIỂM TRA KERBEROS & LDAP PORT ===" -ForegroundColor Cyan
Test-NetConnection -ComputerName localhost -Port 88   # Kerberos
Test-NetConnection -ComputerName localhost -Port 389  # LDAP
Test-NetConnection -ComputerName localhost -Port 636  # LDAPS

Write-Host "`n=== 3. KIỂM TRA DCDIAG & AD ADVERTISING ===" -ForegroundColor Cyan
dcdiag /test:Advertising /test:Services /test:SysVolCheck

Write-Host "`n=== 4. QUÉT EVENT LOGS TÌM LỖI CRITICAL / ERROR (24H QUA) ===" -ForegroundColor Cyan
$Logs = @("Directory Service", "DNS Server", "DFS Replication", "System")
foreach ($Log in $Logs) {
    Write-Host "--- Log: $Log ---" -ForegroundColor Yellow
    Get-WinEvent -LogName $Log -MaxEvents 20 -ErrorAction SilentlyContinue | 
        Where-Object {$_.LevelDisplayName -eq "Error" -or $_.LevelDisplayName -eq "Critical"} |
        Select-Object TimeCreated, Id, Message | Format-Table -AutoSize
}
```

## WORK PACKAGE 02 (WP-02): SAFE ACCOUNT HARDENING, AUDIT POLICY & PASSWORD CHECK

### 1. Problem Analysis & Objective (WHY)

- **WHY:** `LastLogonDate` không phản ánh chính xác 100% tài khoản active (do các máy Server/Service Accounts ít khi log on trực tiếp). Việc vô hiệu hóa nhầm tài khoản dịch vụ có thể làm dừng hệ thống ERP, Kế toán hoặc Camera.
    
- **HOW:** Triển khai quy trình an toàn 4 bước: **Detect -> Review -> Approve -> Disable**, sử dụng kết hợp `lastLogonTimestamp`, `pwdLastSet`, `Description`, `MemberOf` và thực hiện **Backup thuộc tính User** trước khi tác động.
    

### 2. Workflow An Toàn 4 Bước (Detect -> Review -> Approve -> Disable)

```

│  1. DETECT     │     │  2. REVIEW     │     │  3. APPROVE    │     │  4. DISABLE    │
│ (PowerShell)   │ ──> │ (IT & Managers)│ ──> │ (IT Director/  │ ──> │ (PowerShell    │
│ Multi-Attribute│     │ Exclude Admin/ │     │ BOD Sign-off)  │     │ Execution)     │
│ Export CSV     │     │ Service Account│     │                │     │ Backup First!  │
└────────────────┘     └────────────────┘     └────────────────┘     └────────────────┘
```

### 3. Execution Scripts (Phase-by-Phase)

#### Step 1: Detect & Export Multi-Attribute Data (Không tác động hệ thống)

PowerShell

```
# ==============================================================================
# SCRIPT: WP02_Step1_Detect_Inactive_And_PassPolicy.ps1
# DOMAIN: qve.com
# CÔNG DỤNG: Quét đa thuộc tính để phát hiện User Inactive & Password Never Expires
# ==============================================================================

$ExportDir = "C:\AD_Audit_Reports"
New-Item -ItemType Directory -Path $ExportDir -Force | Out-Null

Write-Host "[+] 1. Quét tài khoản Inactive > 90 ngày (Multi-Attribute)..." -ForegroundColor Cyan
$Days = 90
$Time = (Get-Date).AddDays(-$Days)

Get-ADUser -Filter {Enabled -eq $true} -Properties lastLogonTimestamp, pwdLastSet, Description, MemberOf, PasswordNeverExpires, Manager |
    Where-Object {
        $LastLogon = [DateTime]::FromFileTime($_.lastLogonTimestamp)
        $LastLogon -lt $Time -and $_.SamAccountName -ne "krbtgt" -and $_.SamAccountName -ne "Guest"
    } | Select-Object SamAccountName, Name, 
        @{N='LastLogon';E={[DateTime]::FromFileTime($_.lastLogonTimestamp)}},
        @{N='PasswordLastSet';E={$_.pwdLastSet}},
        PasswordNeverExpires, Description, Manager,
        @{N='Groups';E={$_.MemberOf -join '; '}} |
    Export-Csv -Path "$ExportDir\Inactive_Users_Review_List.csv" -NoTypeInformation -Encoding UTF8

Write-Host "[+] 2. Quét tài khoản có cấu hình 'Password Never Expires'..." -ForegroundColor Cyan
Get-ADUser -Filter {PasswordNeverExpires -eq $true -and Enabled -eq $true} -Properties MemberOf, Description |
    Select-Object SamAccountName, Name, Description, @{N='Groups';E={$_.MemberOf -join '; '}} |
    Export-Csv -Path "$ExportDir\Password_Never_Expires_List.csv" -NoTypeInformation -Encoding UTF8

Write-Host "[SUCCESS] Xuất file Review thành công tại: $ExportDir" -ForegroundColor Green
```

#### Step 2: Backup User State trước khi Disable (Sau khi đã có phê duyệt)

PowerShell

```
# ==============================================================================
# SCRIPT: WP02_Step2_Backup_User_Group_Membership.ps1
# DOMAIN: qve.com
# CÔNG DỤNG: Sao lưu danh sách Group Membership của các User chuẩn bị bị Disable
# ==============================================================================

$ApprovedCSV = "C:\AD_Audit_Reports\Inactive_Users_APPROVED.csv" # File đã được phê duyệt
$BackupStatePath = "C:\AD_Audit_Reports\User_State_Backup_$(Get-Date -Format 'yyyyMMdd').csv"

if (Test-Path $ApprovedCSV) {
    $UsersToDisable = Import-Csv $ApprovedCSV
    $UserData = foreach ($U in $UsersToDisable) {
        $ADUser = Get-ADUser -Identity $U.SamAccountName -Properties MemberOf, Department, Title, DistinguishedName
        [PSCustomObject]@{
            SamAccountName    = $ADUser.SamAccountName
            DistinguishedName = $ADUser.DistinguishedName
            Department        = $ADUser.Department
            Title             = $ADUser.Title
            Groups            = ($ADUser.MemberOf -join ';')
        }
    }
    $UserData | Export-Csv -Path $BackupStatePath -NoTypeInformation -Encoding UTF8
    Write-Host "[+] Đã lưu bản Sao lưu trạng thái User tại: $BackupStatePath" -ForegroundColor Green
} else {
    Write-Warning "Không tìm thấy file APPROVED CSV. Hãy hoàn tất bước Review & Approve trước!"
}
```

### 3. Execution Script: Advanced Asset & Zombie Computer Collector

Chạy Script này trên **MGMT-VM01.qve.com** (Tên miền `qve.com`):

PowerShell

```
# ==============================================================================
# SCRIPT: WP03_Advanced_Asset_And_Zombie_Collector.ps1
# DOMAIN: qve.com
# CÔNG DỤNG: Thu thập tài sản AD nâng cao, phát hiện Zombie Computers & Phân Tier chuẩn
# ==============================================================================

$ReportPath = "C:\AD_Audit_Reports\Advanced_Asset_Tiering_qve_com_$(Get-Date -Format 'yyyyMMdd').csv"

Write-Host "[+] Đang quét toàn bộ tài sản máy tính trong Domain qve.com..." -ForegroundColor Cyan
$Computers = Get-ADComputer -Filter * -Properties OperatingSystem, OperatingSystemVersion, Enabled, LastLogonDate, Description, ManagedBy, CanonicalName, DNSHostName

$Results = foreach ($Comp in $Computers) {
    $OS = $Comp.OperatingSystem
    $Tier = "UNKNOWN"
    
    # 1. Phân loại Tiering Kỹ lưỡng
    if ($OS -like "*Linux*" -or $OS -like "*Ubuntu*" -or $OS -like "*RedHat*" -or $OS -like "*CentOS*") {
        $Tier = "Tier-Linux (Linux Infrastructure)"
    }
    elseif ($OS -like "*Windows 11*" -or $OS -like "*Windows 10*" -or $OS -like "*Server 2019*" -or $OS -like "*Server 2022*") {
        $Tier = "Tier-A (Modern OS)"
    }
    elseif ($OS -like "*Windows 7*" -or $OS -like "*Server 2012*" -or $OS -like "*Server 2008*") {
        $Tier = "Tier-B (Extended Legacy)"
    }
    elseif ($OS -like "*XP*" -or $OS -like "*Server 2003*" -or $OS -eq $null) {
        $Tier = "Tier-C (Restricted Legacy / CNC)"
    }

    # 2. Kiểm tra Live Ping (Phát hiện Zombie Computers)
    $PingStatus = "OFFLINE/ZOMBIE"
    if ($Comp.Enabled -eq $true) {
        if (Test-Connection -ComputerName $Comp.Name -Count 1 -Quiet) {
            $PingStatus = "ONLINE"
        }
    } else {
        $PingStatus = "DISABLED"
    }

    [PSCustomObject]@{
        ComputerName     = $Comp.Name
        DNSHostName      = $Comp.DNSHostName
        Enabled          = $Comp.Enabled
        PingStatus       = $PingStatus
        AssignedTier     = $Tier
        OperatingSystem  = $OS
        OSVersion        = $Comp.OperatingSystemVersion
        OUPath           = $Comp.CanonicalName
        Description      = $Comp.Description
        ManagedBy        = $Comp.ManagedBy
        LastLogonDate    = $Comp.LastLogonDate
    }
}

$Results | Export-Csv -Path $ReportPath -NoTypeInformation -Encoding UTF8
Write-Host "[SUCCESS] Xuất báo cáo tài sản nâng cao thành công tại: $ReportPath" -ForegroundColor Green
```
