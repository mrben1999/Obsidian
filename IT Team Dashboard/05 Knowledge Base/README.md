# Knowledge Base

## Mục đích

Knowledge Base là kho tri thức IT tập trung, dùng để:
- Tra cứu hướng dẫn xử lý sự cố
- Lưu trữ best practices
- Hỗ trợ đào tạo nhân sự mới
- Cung cấp tham khảo cho AI Agent phân tích ticket

## Phạm vi

| Bao gồm | Không bao gồm |
|---------|---------------|
| Hướng dẫn xử lý sự cố | Dữ liệu nhạy cảm (password, secret) |
| Best practices | Thông tin cá nhân nhân viên |
| Checklist vận hành | Tài liệu dự án đang thay đổi |
| FAQ | Báo cáo tài chính |

## Quy tắc sử dụng

1. **Đọc**: Ai cũng có thể đọc, tra cứu
2. **Chỉnh sửa**: Chỉ IT Team được chỉnh sửa
3. **Tạo mới**: Cần IT Manager phê duyệt
4. **Xóa**: Không xóa, chuyển vào Archive nếu lỗi thời
5. **Đặt tên**: `[ID]-[Chủ đề].md` (ví dụ: `HARD-001-Laptop-khong-khoi-dong.md`)

## Cấu trúc thư mục

| Thư mục | Chủ đề |
|---------|--------|
| 01-Hardware | Phần cứng (PC, Laptop, Monitor, Phone) |
| 02-Network | Mạng (Switch, Router, AP, Firewall) |
| 03-Printer | Máy in, máy scan |
| 04-Windows | Hệ điều hành Windows |
| 05-Microsoft365 | Office 365, Azure AD, Teams |
| 06-GLPI | Hệ thống quản lý ticket GLPI |
| 07-Zabbix | Giám sát hạ tầng Zabbix |
| 08-FAQ | Câu hỏi thường gặp |
