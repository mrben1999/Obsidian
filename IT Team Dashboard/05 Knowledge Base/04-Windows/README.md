# Windows Knowledge Base

## Mục đích

Knowledge về hệ điều hành Windows: cài đặt, cấu hình, troubleshooting.

## Khi nào sử dụng

- Sự cố Windows
- Cài đặt phần mềm
- Cấu hình Group Policy
- Xử lý lỗi BSOD, slow, update
